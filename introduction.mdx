## Overview

Henry Xiang provides a centralized platform where you create, organize, and manage all your project documentation. You build structured spaces for teams to collaborate seamlessly, version docs, and search content effortlessly. Start organizing your knowledge base today without complex setups.

## Quick Start

Get up and running in minutes:

<Steps>
  <Step title="Sign Up" icon="user-plus">
    Visit `https://henryxiang.com` and create your free account. No credit card required.
  </Step>
  <Step title="Create a Space" icon="folder-plus">
    Click "New Space" and name it for your project, like "MyApp Docs".
  </Step>
  <Step title="Add Your First Page" icon="plus">
    Start with a blank page or import from Markdown. Use the editor for rich content.
  </Step>
  <Step title="Invite Collaborators" icon="mail">
    Share your space link and add team emails for instant access.
  </Step>
</Steps>

## Quick Navigation Guide

Navigate Henry Xiang efficiently using these paths:

<Tabs>
  <Tab title="Dashboard" icon="layout">
    Access your spaces overview from `/dashboard`. View recent activity and search globally.
  </Tab>
  <Tab title="Spaces" icon="folders">
    Manage all spaces at `/spaces`. Create, archive, or export entire documentation sets.
  </Tab>
  <Tab title="Settings" icon="settings">
    Configure themes, integrations, and permissions under `/settings`.
  </Tab>
</Tabs>

<CodeGroup tabs="CLI,API">
  ```bash
  # Install Henry Xiang CLI
  npm install -g @henryxiang/cli

  # Login and create space
  henry login
  henry space create "MyProject"
  ```
  ```javascript
  // API example to list spaces
  const response = await fetch('https://api.henryxiang.com/spaces', {
    headers: { Authorization: `Bearer ${YOUR_API_KEY}` }
  });
  const spaces = await response.json();
  console.log(spaces);
  ```
</CodeGroup>
